# 幸运硬币

一个当铺主题的老虎机 roguelike。单文件网页，无依赖、无外部请求，打开就能玩。

**试玩：** https://nax-sec.github.io/lucky-coin/

---

## 怎么玩

拉下盘面右边的**拉杆**（或按空格）转动。每个符号按自己的规则结钱，结算按符号成组播报，**金额最大的一组压轴**——那通常就是你这局的主力。嫌慢可以点盘面或按空格快进。

- **5 期 = 1 关，共 5 关。** 每期 5 转，关的最后一期要交租，交不上就关门。
- 中间每一期结束都能进**商店**：符号、道具、整理次数都要花铜钱买。
- **摧毁 = 永久移出符号池。** 猫吃鼠、熊吃蜜、钥匙开箱都会真的消耗掉那个符号，换来一大笔钱。
- **道具位只有 12 个**，想要新的就得舍掉旧的（道具册里点两下舍弃换半价）。
- **同族道具凑成套会出倍率**，比如「灯油 + 百宝箱 → 器物 ×1.35」。道具册里能看到还差哪件。
- 点盘面上的符号或右侧的道具，会弹出它的效果说明；月亮、黑洞会显示当前累积倍率。

开局有三副随机起手让你挑，各自指向不同路子。

## 已知的粗糙处

- 没有存档，关掉页面就没了
- 通关后的无尽模式目前只是把关卡续下去，还没有专属机制
- 平衡还在调，难度偏硬

## 结构

```
index.html    可直接部署的完整页面（由 build.sh 生成，不要手改）
source/       真源。片段形式，没有 <head>
build.sh      给片段包上 HTML 外壳
```

改动请改 `source/index.html`，然后跑 `./build.sh`。
